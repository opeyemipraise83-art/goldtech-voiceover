Engine setup & connection

Run the notebook on a free GPU, then paste the https://….trycloudflare.com URL it prints. One notebook works on all three platforms.

Kaggle

T4 x2 · ~30h/wk
Open Kaggle ↗
  1. Import GOLDTECH_Voice.ipynb (File → Import Notebook).
  2. Settings → Internet ON · GPU T4 x2.
  3. Run All; copy the tunnel URL from the last cell.

Google Colab

T4 · free tier
Open Colab ↗
  1. Upload/open GOLDTECH_Voice.ipynb.
  2. Runtime → Change runtime type → T4 GPU.
  3. Run all; copy the tunnel URL from the last cell.
Optional Google Drive prompt only caches the model so it doesn't re-download each session. It does not store your voice.

Lightning AI

  3. Run All; copy the tunnel URL from the last cell.
